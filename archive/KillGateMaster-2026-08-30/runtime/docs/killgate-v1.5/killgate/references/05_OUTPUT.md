# Output Protocol

Start with the verdict and what it does / does not mean.

1. Verdict + confidence. If FEASIBILITY_REQUIRED, put the locked capability test and thresholds in section 10, not a buyer-count plan.
2. Locked hypothesis
3. Gate scoreboard
4. Mechanism scoreboard — role, action (KEEP/TEST/REMOVE_DEFER/CONTRADICTED), whether the row changes the commercial hypothesis
5. Strongest evidence FOR
6. Strongest evidence AGAINST
7. Evidence audit — facts / inferences / unknowns / contradictions / excluded
8. Why the verdict follows, citing the locked rule
9. Build-risk memo — commentary only; cannot upgrade verdict
10. Minimum next action
11. What would change the verdict

If RESEARCH_PASS with REMOVE_DEFER, state the implementation lock in the next-action section without minting a new hypothesis fingerprint.
