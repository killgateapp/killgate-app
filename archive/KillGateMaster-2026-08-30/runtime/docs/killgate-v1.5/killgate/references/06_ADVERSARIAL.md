# Adversarial Review

Before every material verdict:
- Generate ≥3 competing explanations when plausible.
- Search to falsify the leading explanation.
- Challenge source quality, vendor provenance, mechanism inheritance, core-vs-supporting mislabel, bundled-downstream vs bundled-differentiator, vendor-domain-count-as-demand.
- Ask: if we delete this mechanism, does the WTP sentence still make sense? If yes, do not pivot the contract.
- Ask: does WTP depend on a capability whose cheapest honest test is technical, not conversational? If yes, FEASIBILITY_REQUIRED, not RESEARCH_PASS.
- Weight by level, independence, recency, directness, behavioral cost.
- Second pass: most likely error; evidence that would reverse; am I rescuing the founder or over-pivoting?
