## Purpose

This release consolidates the newest available Killgate code and product rules into one source package and replaces the prior high-volume subscription concept with a metered, idea-centered monetization system.

The validation methodology/contract remains **v1.5**. The application/runtime version is **v1.2.0**.

## Source precedence used

1. August 28 monetization/runtime branch for the broadest current working tree.
2. August 27 v1.5 merged source for newer validation-engine/security behavior where applicable.
3. August 26 archive/handoff content only when it supplied material not superseded by the newer runtime.
4. Older artifacts are retained under `extras/` for provenance rather than allowed to overwrite the authoritative runtime.

## Final commercial contract

| Offer | Price | Entitlement |

| Venture Pass | $19.99 | 3 live research passes on one idea family |

| Founder Pro | $59.99/month | 9 live research passes each verified billing period |

There is no unlimited plan and no customer-facing 30-run monthly allowance.

## Material implementation changes

### Google Play billing
- Canonical SKU environment variables and Play product IDs updated to the new four-product catalog.
- One-time consumables are verified server-side, durably granted, then consumed through Google Play so they can be purchased again.
- Founder Pro is acknowledged only after entitlement persistence.
- Founder Pro credits refill once per verified billing period instead of once per purchase token.
- RTDN renewal processing grants the new monthly period exactly once.

### Durable paid-research wallet
- Production wallet operations now use service-role Supabase RPCs.
- Venture Pass and Evidence Run binding/debits are atomic.
- Top-up eligibility is rechecked server-side against active subscription entitlement.
- A new idempotent `killgate_wallet_refund` path restores an undelivered paid debit exactly once.
- Local JSON wallet storage remains a development-only backend.

### Research execution
- A successful paid debit is treated as a reservation until the research result is recorded.
- Provider failure, unexpected execution failure, stale-state conflict, or durable state-store failure restores the paid entitlement before the failed run can be retried.
- The 30-run rolling-30-day value is an API safety ceiling only; it is not a purchased entitlement. Internal beta access is separately allowlisted for 9 free runs during a 14-day window.

### UI / product language
- Free preview is explicitly a research brief, not leaked research.
- Venture Pass is the default offer.
- Extra Evidence Run is shown only in an idea context.
- Founder Pro is positioned for serial founders/consultants rather than as the default.
- Pro Top-Up is shown only when active Pro can be established.
- Old 8-credit / 30-run / unlimited language was removed from live product semantics.

### Version/cache
- Runtime/PWA version: `1.2.0`.
- Validation engine/contract remains `v1.5`.
- Service-worker cache version bumped so existing installs do not retain stale pricing UI.
