# Killgate engine — 26 August 2026

Portable TypeScript adaptive validation gate.

- `evaluator.ts` — GO_BUILD / GO_SELL / CONTINUE / PIVOT / KILL
- `profile.ts` — lock + SHA-256 fingerprint
- `slots.ts` — three live locks
- `packet.ts` — evidence packet
- `*.test.ts` — run with `node --experimental-strip-types --test *.test.ts`

This folder does not include the UI. For the working product, use Killgate-PWA-2026-08-26.zip.
